## 📌 脚本简介

**酒馆生图助手 v2.0** 是一款为 SillyTavern 深度定制的图像生成辅助脚本，专注服务于 **NovelAI** 用户。它能够自动从对话中提取视觉线索，生成高质量的生图提示词，并直接调用 NovelAI API 完成出图 —— 让每一段精彩对话都能拥有专属的画面。

> 💡 **设计理念**：将 NovelAI 生图能力无缝融入酒馆聊天流程，做到“聊到哪里，图就出到哪里”。

## 🧩 功能模块详解

### 1. 🔌 直连 NovelAI 引擎

- 直接调用 NovelAI 官方 API，无需依赖酒馆内置 `/sd` 扩展
- 支持 **V5 / V4.5 / V4 / V3** 全系列模型，默认使用 `nai-diffusion-5-full`
- 内置 **Quality+ / Variety+ / SMEA / Decrisper** 等官方进阶参数
- 支持 **透明背景生成**（V5 原生特性）
- 支持 **多角色分层解析**（使用 `<char>特征...</char>` 独立描绘多名角色，V5 最高 32 角色）

---

### 2. 📜 任意历史消息生图

**不再局限于最新一条对话生图。**

你可以在聊天记录中 **任选一条消息** 作为生图依据：
- 为过去的某个高能场面单独补图
- 为特定转折点重新生成
- 让每个对话节点都拥有独立的画面

> 不同角色的聊天记录依然相互隔离，切换窗口不会串图。

---

### 3. 👥 多角色独立特征提取与管理

- 为 **每个角色单独配置固定特征标签**（外貌、发型、瞳色、体型等）
- 生图时自动叠加对应角色的固定特征，防止 AI 随机性导致的形象崩坏
- 支持 **一键智能提取**：点击角色卡的「✨ 智能提取特征」，AI 自动从角色卡描述中提取外貌标签
- 支持 **智能扫描聊天记录**：自动识别最近对话中出场的人物并批量添加

---

### 4. 🎨 画风预设管理 + 图浏览

- **前后缀与负面提示词可保存为多套预设**，适配不同模型或画风偏好
- **角色专属画风绑定**：可为每个角色绑定特定的画风预设，不同角色使用不同画风
- **新增图浏览功能**：调整前后缀 / 负面词时，点击「生成画风样例」即可预览效果，告别盲调

| 预设类型 | 说明 |
|----------|------|
| 画风预设 | 存储 `prefix` / `suffix` / `negative` 组合 |
| 模型(API)预设 | 存储 LLM 接口配置（Base URL / API Key / 模型 / 参数） |
| 提示词模板 | 存储注入 AI 的提示词模板（含人物列表占位符） |
| 独立生词模板 | 存储独立 API 模式的对话模板 |
| AI修改模板 | 存储 AI 修改图片提示词的对话模板 |
| 人物特征模板 | 存储角色特征提取的提示词模板 |

---

### 5. 📦 队列与流式生图

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **顺序队列生图** | 多张图按顺序一张张生成，生成完再发下一张 | NovelAI（防并发报错） |
| **并发队列生图** | 每次批量处理多张图（可调并发数） | 需要快速批量出图 |
| **流式生图** | 在 AI 流式输出期间实时检测并立即生图 | 实时性要求高的场景 |

- 队列支持 **进度 Toast 显示** 和 **一键终止队列**
- 流式生图支持 **自动去重**，避免重复生成相同提示词

---

### 6. ☁️ 多端配置同步

**存储模式：酒馆服务端为主，浏览器本地为辅**

- 配置自动保存到酒馆的 `extensionSettings`（跨设备持久化）
- 同时备份到 `localStorage`（离线兜底）
- 切换窗口焦点时自动检测服务端更新并热加载
- 设置面板中可手动「从酒馆拉取」或「推送到酒馆」

> ✅ 电脑和手机连接到同一个酒馆时，配置自动同步，无需手动迁移。

---

### 7. 🛠️ 智能异常诊断与恢复

生图失败时，脚本会自动分析错误类型并给出针对性建议：

| 诊断类型 | 典型原因 | 建议操作 |
|----------|----------|----------|
| `HTTP_ERROR` | API Key 无效或网络不通 | 检查 API 配置 |
| `TRUNCATED_TOKENS` | 最大 Token 不足，输出被截断 | 调大 maxTokens |
| `SCHEMA_MISMATCH` | JSON 结构不符合规范 | 检查独立生词模板 |
| `NO_JSON_FOUND` | 模型输出自然语言而非 JSON | 调低 Temperature，调整模板 |
| `AUTH_ERROR` | Token 鉴权失败 (401/403) | 检查 NovelAI Token |
| `QUOTA_ERROR` | 账户点数不足 (429) | 充值 Anlas |
| `TIMEOUT` | 生图请求超时 | 调大超时时间或检查网络 |
| `CONNECTOR_LOAD_FAILED` | 连接器未加载 | 重新拉取远端连接器 |

- 点击错误 Toast 上的「查看诊断」按钮，弹出完整的诊断面板
- 诊断面板包含：错误原因分析、建议修复方案、一键修复按钮、原始返回内容、日志流水
- 支持 **导出完整诊断日志 (.json)** 和 **复制 Markdown 排查报告**

### 8. 📤 配置导入导出

| 功能 | 说明 |
|------|------|
| **导出全部配置** | 导出为 `.json` 文件，包含所有设置、模板、人物列表、预设等 |
| **导入全部配置** | 从 `.json` 文件恢复配置 |
| **导出单个模板** | 支持标准 Schema 格式，可单独导出提示词模板 / 独立生词模板 / AI修改模板 / 人物特征模板 |
| **导入单个模板** | 支持标准 Schema 格式导入，自动校验与类型匹配 |

---

### 9. 🖼️ 沉浸式图库体验

- **点击图片** → 弹出大图查看器（Lightbox），展示正向/负向提示词、生成参数（模型/预设/分辨率/采样器/CFG/步数/种子等）
- **左右箭头** → 切换同一条消息中的多张图片
- **垃圾桶图标** → 删除当前图片
- **铅笔图标** → 编辑提示词，支持 AI 辅助修改
- **魔法棒图标** → 触发新图生成
- **折叠箭头** → 折叠/展开图片区域

## 📥 快速上手

### 安装步骤

1. **准备 NovelAI 账户与 API Token**
   - 登录 NovelAI，进入账户设置 → 获取持久访问令牌（`pst-xxx`）

2. **安装脚本**
   - 将 `酒馆助手脚本.json` 导入酒馆助手的脚本扩展列表

3. **配置脚本**
   - 点击酒馆顶部「生图助手」菜单项打开设置
   - 进入「模型配置」→ 选择 NovelAI → 填入 API Token → 点击测试连接
   - 进入「人物&前后缀」→ 添加角色并配置固定特征标签
   - 进入「基本设置」→ 调整生图参数（间隔、重试、超时等）

4. **开始使用**
   - 在聊天中点击任意 AI 消息旁的 🖼️ 按钮 → 自动提取生图
   - 或点击图片框的魔法棒图标手动触发生图

## ⚡ 与原版的区别

| 对比项 | 原版 | v2.0 (本脚本) |
|--------|------|---------------|
| **目标平台** | 通用（ComfyUI / NovelAI / 视频） | **仅 NovelAI（专注）** |
| **生图模型** | 多平台可选 | **NovelAI V5/V4.5/V4/V3** |
| **历史消息生图** | ❌ 仅最新消息 | ✅ **任意历史消息** |
| **多角色提取** | 基础 | ✅ **增强（智能提取+扫描）** |
| **画风图浏览** | ❌ | ✅ **生成样例预览** |
| **队列并发控制** | 简单队列 | ✅ **可调并发数（1~10）** |
| **多端同步** | localStorage | ✅ **酒馆服务端优先** |
| **异常诊断** | 基础日志 | ✅ **智能诊断 + 一键修复** |
| **代码体量** | ~4000 行 | ~4500 行（功能更丰富） |
| **冗余模块** | ComfyUI / 图生视频 / 独立API | ✅ **已全部移除** |
