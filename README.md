# 🎴 酒馆生图助手 · NovelAI 专属轻量版

基于 walkeatround 原版生图助手插件精简强化而来，**全面聚焦 NovelAI 平台**，砍掉独立 API 生词、图生视频等冗余模块，让生图流程更纯粹、更轻快。同时针对实际使用痛点进行了多项增强，尤其适合需要高频、多角色、精细控图的酒馆玩家。

## ✨ 核心特性

### 1. 深度 NovelAI 集成，全系列模型制霸
- 直连 NovelAI，支持 **V4.5 / V3 全系列模型**
- 内置 **Quality+ / Variety+** 等进阶标签，画质优化算法一步到位
- **自定义生图数量**：不再只出一张，可自由设定每次生成张数，批量出图更尽兴

### 2. 对话级别独立生图，任意历史消息都能出图
**不再局限于最新一条对话生图**。你可以在聊天记录中任选一条消息作为生图依据，为过去的某个高能场面、特定转折点单独补图，每个对话节点都能独立触发图片生成。想重现第三轮对话里的初见场景？直接点一下就行。

不同角色的聊天记录依然相互隔离，切换窗口不会串图，管理清晰。

### 3. 每个人物独立定制提取规则
- **更新自定义提取每个人物**：为每个角色单独配置需要提取的特征字段（外貌、衣着、发型、瞳色等）
- **优化文本过滤与提取**：智能过滤聊天中的语气词、动作描写等干扰，只抓取有效设定信息，生成的提示词更干净精准

### 4. 提示词预设全面增强 · 新增图浏览
- 前后缀与负面提示词均可保存为多套预设，适配不同模型或画风
- **管理界面新增图浏览功能**：调整前后缀 / 负面词时可直接预览对应的效果图，方便对比不同参数的影响，调整更直观

### 5. 角色特征一致性保障
- 可为每个角色配置**专属固定提示词**（如“红发、双马尾、黑色水手服”）
- 连续生图时自动叠加，有效防止 AI 随机性导致的形象崩坏，保持角色高度统一

### 6. 沉浸式图库与效率工具
- 聊天界面直接预览大图，支持快速切换历史图片、删除废图、一键重绘
- 流式生图、请求超时保护、配置一键导入导出……那些好用的辅助功能都为你保留

## 📥 快速上手
1. **准备 NovelAI 账号与 API Key**（需订阅可用生图的会员档位）
2. 将脚本导入酒馆助手的脚本扩展列表
3. 在插件设置中填入 API Key，按角色调整提取规则与生图预设
4. 在聊天记录中点击任一对话旁边的生图按钮，或使用指令，即可基于该条消息出图

## ⚡ 与原版的区别
- **专一平台**：仅保留 NovelAI 生图，移除独立 API 生词、ComfyUI、图生视频等模块，体量更轻
- **更细的控制粒度**：任意历史对话生图、增强的单角色提取规则、自定义出图数量等，都是原版没有的优化
- **更直观的预设管理**：新增图浏览，让提示词调整不再“盲调”

如果你需要一个无需复杂配置、专注 NovelAI 且能让你从任何一句话“就地出图”的酒馆生图利器，这就是为你准备的版本。
